# RokuPad

Controle remoto para TV Roku com touchpad, teclado, lista de apps e volume pelos botões do celular.

## Como gerar o APK
1. Suba esta pasta para um repositório no GitHub (branch `main`).
2. O GitHub Actions compila sozinho (aba **Actions**, ~3 min).
3. O APK aparece em **Releases → RokuPad (APK)**. Abra pelo celular, baixe e instale
   (permita "instalar apps desconhecidos" para o navegador quando pedir).

## Na TV
Configurações > Sistema > Configurações avançadas do sistema > Controle por apps móveis > Acesso à rede: **Padrão**.
Celular e TV no mesmo Wi-Fi.
